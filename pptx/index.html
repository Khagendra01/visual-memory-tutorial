02

Concept

The meaning of "last seen"

A dated observation supports the answer. Hidden movement remains unknown.

What "last seen" means

  • Glasses observed on side table at 9:12
  • Someone moves them while camera looks away
  • Record still describes that earlier sighting
  • Does not establish current location

Different questions

  • Recognition — is this the same object?
  • Identity matching — is this my glasses?
  • Episodic memory — where was it last seen?

Ego4D visual-query task — use an example image to return a previous response track. The interface should show evidence image, place, and timestamp. [1]

04

Geometry

Pixel, depth, and camera pose

Relocalization must restore the saved coordinate system before guidance.

Projection chain

  • Calibrated pixel + depth → camera-space point
  • Rotation & translation → world coordinates
  • Example: depth = 2 m, tx = 1 m → point (1.2, 0.1, 2.0)

Watch the convention: world-to-camera and camera-to-world are inverses.

Relocalization

New session must align with the saved map before any directional guidance is issued.

Warning: a precise-looking arrow is misleading if the maps do not agree.

Sources: ORB-SLAM3 [4] · EgoLoc [5] · ARKit world maps [6]

08

Honesty

Limits and evaluation

Failure modes

  • Unseen movement
  • Occlusion and similar objects
  • Map drift and session changes
  • Mobile resource limits

Evaluation

  • Correct last-seen retrieval
  • False confident answers
  • Abstention and coverage
  • Position and relocalization errors

Every useful answer includes its evidence, observation time, and uncertainty.
