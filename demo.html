05 / Interactive lab

What does the memory actually know?

Move an object with and without observation, then inspect the answer.

Listen to this pageAudio summary · synthetic voice
Read the audio transcript

This lab separates physical reality from stored memory. Start by moving the glasses to the sofa while the camera observes. A high-quality observation updates the record. Next, turn observation off and move the glasses to the shelf. The orange point shows the simulated real position, but the stored answer still names the sofa. A real application would not have the orange point. Now advance time by forty minutes to trigger a stale-memory response. Reset and turn off map alignment to suppress geometric guidance. You can also lower the quality score to reject an observation. Try the wallet, which initially has no record. The displayed distance is a straight-line displacement and does not describe a safe route. Spend about three minutes on these experiments and explain which evidence each answer uses.

Teaching simulation. Coordinates, scores, and times are synthetic. No camera, microphone, model download, or network request is used. All state resets when you reload.
Select an object and ask for its last-seen location.



Try these three experiments
  1. Observe a move: select the glasses, choose Sofa, leave observation checked, and apply the move. Query the memory. Its timestamp and location should update.
  2. Hide a move: uncheck observation, move the glasses to Shelf, and query again. The physical dot moves, but the stored answer stays at Sofa. A real application would not have access to the orange ground-truth dot.
  3. Break an assumption: advance 40 minutes or turn off map alignment. The assistant should retain historical evidence while withholding geometric guidance. Reset and try a quality score below 0.80 to see an update rejection.


Interpreting the output
The reported distance is Euclidean displacement from the simulated phone. A straight line can pass through furniture. The demo therefore provides a last-seen cue, not turn-by-turn navigation. Age and observation quality are separate: an excellent photograph from yesterday is strong evidence of yesterday's location, but weak evidence of the current one.
Try Wallet to see the unknown state. Then observe a high-quality move of the wallet and query again. This makes the difference between “not in memory” and “known to be absent” visible. Neither state establishes that an object is outside the room.


Pause & explain: Why does the hidden move not change the stored answer?
The update algorithm receives no new observation. In reality the system cannot know whether a hidden move happened. Its answer must remain a dated last-seen claim.
