An object memory is only as reliable as the observations written into it. First detect an object, then associate it across nearby frames, and match it to an enrolled identity. Use several views because a single crop may look different under rotation or lighting changes. A similarity score is not a probability. The Python example accepts an observation only when both illustrative quality scores exceed point eight. It also prevents an older observation from overwriting a newer one. Retrieval checks whether the memory is missing, stale, or attached to a different map. Only then does it calculate displacement. The thresholds are teaching choices that require validation. This code begins after perception and does not implement detection or SLAM. A fuller system should retain uncertain sightings and conflicting evidence instead of simply discarding them.
