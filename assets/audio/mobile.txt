Our proposed mobile design starts with a small set of enrolled objects. A detector finds candidates, an appearance model checks identity, and a local database retains selected observations. A simple object picker or phrase parser can answer common requests without a large language model. Quantization can reduce weight storage, but measure accuracy again, particularly for small objects. Ten million weights need about forty megabytes in thirty-two-bit floating point and ten megabytes in eight-bit integers, excluding runtime overhead. Local data still needs protection and explicit deletion. Keep recording visible and verify backup behavior. Accessibility includes large controls, readable text, replayable speech, and choices beyond augmented reality. Evaluate the workflow with intended users. Finally, measure sustained performance on the actual phone rather than assuming a desktop benchmark transfers to mobile hardware.
