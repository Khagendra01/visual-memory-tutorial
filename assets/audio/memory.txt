Recognition and memory answer different questions. Category detection might label two objects as wallets. Instance matching asks which wallet matches an enrolled example. Episodic retrieval asks when that particular wallet was last seen. Visual Query two D returns an interval of bounding boxes in a previous video. Visual Query three D adds spatial localization relative to a camera pose. CocoFormer improves query conditioned detection by considering the context of other proposals and addressing training bias. E SOM builds a memory while frames arrive, then searches that memory when a query arrives. Remember that offline has two meanings here. An offline research method has access to a complete recording. An offline mobile application operates without an Internet connection. For a small collection of enrolled objects, our design begins with streaming memory and explicit uncertainty.
