This bibliography lists sources in their order of first appearance. Each entry includes authorship, date, publication context, a synopsis, and a reliability assessment. The research papers support the benchmark and algorithm discussion. Apple and Google documentation support specific implementation choices. W three C guidance supports accessibility design. Reliability is scoped: official documentation is authoritative for an API, but it does not prove that the proposed assistant works in a home. References are numbered by first appearance along the tutorial route. These are eight distinct works across research, platform documentation, and accessibility guidance. Research papers sharing a host are not treated as different websites. All research summaries, examples, and diagrams use original explanatory wording; no long passages or borrowed figures are reproduced.

[1] Ego4D: Around the World in 3,000 Hours of Egocentric Video

Kristen Grauman, Andrew Westbury, Eugene Byrne, et al.. 2022. CVPR, pp. 18995–19012.

Synopsis: Defines a first-person video benchmark suite. The linked official episodic-memory documentation explains image-based queries and response tracks.

Reliability: High for benchmark definitions: primary research and official project documentation. Dataset performance does not establish assistive benefit in homes.

Additional primary-source link

[2] Where Is My Wallet? Modeling Object Proposal Sets for Egocentric Visual Query Localization

Mengmeng Xu, Yanghao Li, Cheng-Yang Fu, Bernard Ghanem, Tao Xiang, Juan-Manuel Pérez-Rúa. 2023. CVPR, pp. 2593–2603.

Synopsis: Introduces CocoFormer and training changes for query-conditioned object proposals. Useful for understanding distractors and task bias.

Reliability: High for the reported experiments: peer-reviewed primary study. Results are task-specific and do not supply mobile deployment measurements.

Additional primary-source link

[3] Online Episodic Memory Visual Query Localization with Egocentric Streaming Object Memory

Zaira Manigrasso, Matteo Dunnhofer, Antonino Furnari, Moritz Nottebaum, Antonio Finocchiaro, Davide Marana, Rosario Forte, Giovanni Maria Farinella, Christian Micheloni. 2026 publication; figures here from arXiv v2, July 22, 2025. WACV, pp. 3951–3960; arXiv:2411.16934v2.

Synopsis: Studies online object memory. Table 1 separates learned configurations from oracle discovery and tracking.

Reliability: High for the explicitly versioned benchmark evidence. Oracle results are conditional; the preprint version is identified so numerical claims are traceable.

Additional primary-source link

[4] ORB-SLAM3: An Accurate Open-Source Library for Visual, Visual-Inertial, and Multimap SLAM

Carlos Campos, Richard Elvira, Juan J. Gómez Rodríguez, José M. M. Montiel, Juan D. Tardós. 2021. IEEE Transactions on Robotics; DOI 10.1109/TRO.2021.3075644.

Synopsis: Describes feature-based SLAM with visual-inertial estimation and multiple maps. Relevant to the camera-pose component.

Reliability: High: peer-reviewed primary systems research with public code. Its test conditions differ from persistent household object memory.

Additional primary-source link

[5] EgoLoc: Revisiting 3D Object Localization from Egocentric Videos with Visual Queries

Jinjie Mai et al.. 2023. ICCV; arXiv:2212.06969v2.

Synopsis: Examines pose availability and multiview aggregation in three-dimensional visual-query localization.

Reliability: High: peer-reviewed primary VQ3D study. Geometry results cannot be directly ranked against VQ2D response-track metrics.

Additional primary-source link

[6] Saving and loading world data

Apple Developer Documentation. Undated; accessed October 6, 2026. ARKit documentation and sample.

Synopsis: Shows how to save mapping data and attempt session relocalization with an initial world map.

Reliability: High for documented Apple APIs. Vendor guidance does not guarantee success in every environment or on every device.

[7] Post-training quantization

Google AI Edge team. Updated May 28, 2026; accessed October 6, 2026. Google for Developers, LiteRT.

Synopsis: Explains precision choices, representative calibration data, and accuracy checks for model conversion.

Reliability: High for supported conversion behavior. Claimed speed benefits depend on model operators, runtime, and hardware.

[8] Older Users and Web Accessibility: Meeting the Needs of Ageing Web Users

W3C Web Accessibility Initiative. Undated on this citation; accessed October 6, 2026. W3C WAI.

Synopsis: Connects older users’ needs with established accessibility principles. Useful for text, control, and multimodal interface decisions.

Reliability: High for standards-oriented accessibility guidance. It is not clinical evidence for this proposed application.
